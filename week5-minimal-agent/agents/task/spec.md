# Task
Prepare this month's expense report from inbox/ as report.md: a table (date, vendor, amount in USD, category, source file) and a list of files left out, each with the reason.

# Why
The school reimburses only business expenses with a matching receipt, in USD. A doubtful item costs me more if claimed than if left out.

# Done
Every file in inbox/ is in the table or the left-out list, and every converted amount shows the rate used.

# Boundaries
✅ Always leave out what is not a receipt, with a reason.
⚠️ Ask first about any expense over $200, or any receipt you cannot read.
❌ Never change or delete anything in inbox/.

inbox/, and the reimbursement policy in policy.md.
